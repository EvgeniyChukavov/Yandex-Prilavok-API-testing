# Отчёт о тестировании новой функциональности API Яндекс.Прилавок

## Что тестировалось
- Работа с наборами: добавление продуктов в набор (POST /api/v1/kits/{id}/products)
- Работа с курьерами: проверка доставки курьерской службой «Привезём быстро» (POST /fast-delivery/v3.1.1/calculate-delivery.xml)
- Работа с корзиной:
  - получение списка продуктов (GET /api/v1/orders/:id)
  - добавление продуктов (PUT /api/v1/orders/:id)
  - удаление корзины (DELETE /api/v1/orders/:id)

## Инструменты
- Postman — отправка запросов
- Apidoc — изучение документации API
- Google Таблицы — ведение чек-листа и баг-репортов

## Список багов по приоритетам

### Критические
- BUG2 — ответ 200 OK при превышении лимита продуктов в наборе
- BUG16 — продукт не добавляется в корзину при id=3
- BUG17 — ответ 404 при удалении существующей корзины
- BUG19 — ответ 200 OK с уменьшением количества при quantity = -1

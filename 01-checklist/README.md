## Описание
Составлен чек-лист для тестирования новой функциональности API Яндекс.Прилавка. Покрыты все ручки: работа с наборами, курьерами и корзиной.

- Лимиты продуктов в наборе
- Структура запроса

### Работа с курьерами (POST /fast-delivery/v3.1.1/calculate-delivery.xml)

- Валидация productsCount, deliveryTime, productsWeight
- Проверка XML-структуры
- Content-Type

- **GET /api/v1/orders/:id** — получение корзины
- **PUT /api/v1/orders/:id** — добавление продуктов
- **DELETE /api/v1/orders/:id** — удаление корзины
